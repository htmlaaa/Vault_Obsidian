## 2. Bug Fix — Regeneración de vida

> [!bug] Bug corregido
> El upgrade **Regeneración** (+1 HP/s) no funcionaba después de equipar un arma.

**Causa raíz**: `Player.recalcStats()` línea 610 sobreescribía `hpRegenPerSec` con solo el bonus del amuleto (`stats.hpRegenPerSec = stats.amuletRegenBonus`), borrando el bonus del upgrade cada vez que el jugador equipaba o desequipaba un arma.

**Fix aplicado** en `entities/Player.java`:
```java
int regenFromUpgrades = upgradeManager != null
    ? upgradeManager.getUpgradeLevel(Upgrade.Tipo.REGENERACION) : 0;
stats.hpRegenPerSec = stats.amuletRegenBonus + regenFromUpgrades;
```
