## 3. Problema de red — CDN Backblaze bloqueada

> [!bug] CDN inaccesible
> `backblaze.pixellab.ai` no respondía desde la red del usuario: `Test-NetConnection` devolvió `TcpTestSucceeded: False` y `PingSucceeded: False`. Los intentos con `Invoke-WebRequest` y `curl.exe` fallaron por timeout.

**Solución**: `api.pixellab.ai` sí era accesible. Se usó el endpoint de descarga oficial de la API de PixelLab con autenticación Bearer:

```
GET https://api.pixellab.ai/mcp/characters/{id}/download
Authorization: Bearer {token}
```

La respuesta es un **ZIP** con esta estructura interna:
```
{NOMBRE_PERSONAJE}/
  rotations/south.png, east.png, north.png, west.png
  animations/{nombre_animacion}/{dir}/frame_000.png ... frame_004.png
metadata.json
```
